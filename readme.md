# Mini application de suivi de tâches

------

# Technologies utilisées

- HTML5, CSS3, JavaScript, Git & GitHub et VScode

------

# Déroulé du projet

- Une tâche sans texte et les espaces ne sont pas ajoutés à la liste
- Le champs de saisie est vide lorqu'une tâche est ajoutée et le curseur est replacé
- Ajout d'un bouton "supprimer" pour chaque élément de la todo-list
- Ajout d'un événement "click" sur le bouton "Ajouter"
- Au click du bouton "supprimer", le texte est éffacé
- Création d'une classe CSS (et d'un fichier style.css) pour que la tache soit barrée quand on a terminé

------

# Dificultés rencontrées

- Trouver la bonne "formule" en lien avec les actions à créer
- Trouver la bonne syntaxe
- Hiérarchiser le code
